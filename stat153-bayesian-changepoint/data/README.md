# Data

`mask_us_google_trends.csv` is the original Google Trends CSV used for this coursework. It contains 254 monthly observations for the search query **mask**, United States, January 2004 through February 2025, with the category set to All categories.

The export is included unchanged. Its first two lines are metadata and a blank line, so the analysis uses `skiprows=2`. Values represent search interest, not raw search counts or counts of mask use. The exact download date was not recorded; a new export may differ from this saved snapshot.

Source: [Google Trends](https://trends.google.com/trends/). The data come from Google Trends, not from the repository author.
